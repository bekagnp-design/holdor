# HOLDOR — დიზაინი v2 (MR B-ს გადაწყვეტილებები, 2026-09-27)

ეს დოკუმენტი აგროვებს MR B-ს გამოკითხვის პასუხებს. თითოეული ვერსია აქედან იღებს წესებს. ცვლილება → ჯერ აქ.
Raid: Shadow Legends და Kingdom Rush Battles — მხოლოდ მექანიკის რეფერენსი: სახელი, არტი, ეფექტები, მუსიკა არ კოპირდება.

## პრინციპები
- **თამაში რთულია, განვითარებას დიდი მნიშვნელობა აქვს.** სრული Legendary ჩემპიონი ≈ 2–3 თვე ყოველდღიური თამაშით.
- **ჩეთინგისგან დაცვა სავალდებულოა** (მომავალში HOLDOR Coin-ის airdrop). ჯილდოს მხოლოდ სერვერი გასცემს; კლიენტი მხოლოდ თხოვს.
- **ტყუილი არა:** AI მოწინააღმდეგე ყოველთვის ღიად მონიშნულია (🤖 AI), ჯილდოების ფონდში არ მონაწილეობს.
- **ქვეყნები ყველგან:** ქვეყანა = გუნდი; სახლი = კლასი/სტილი.
