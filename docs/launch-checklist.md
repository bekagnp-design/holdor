# HOLDOR — გაშვების ჩეკლისტი (v1.0.72)

ყოველი ნაბიჯი **ერთი-ერთი**: შემდეგზე მხოლოდ წინა დადასტურების შემდეგ გადადი. ვინც `[შენ]`-ია — შენი გასაკეთებელია, `[მე]` — ჩემი.

## 1. სანამ ფული შემოვა
1. `[შენ]` **იურისტი:** Game of Thrones-ის სახელები, ხატები და ბრენდი. მოგების ჩაუწერლობა უფლებებს არ ცვლის (`docs/monetization-marketing.md` §0). ეს ახლავე გადაწყვიტე, მარკეტინგამდე.
2. `[შენ]` **ბოტი:** BotFather-ში `/setdescription`, `/setabouttext`, `/setuserpic`; Mini App-ის ბმული `t.me/HoldorTDBot/play` სწორად იხსნება.
3. `[შენ]` **⭐50 სატესტო ყიდვა** ყველაზე პატარა პაკეტზე ტელეგრამში → `[მე]` ბაზაში ვამოწმებ (`payments`, `ledger`) → **refund** (`refundStarPayment`) → ვამოწმებ, რომ დრაგონგლასი უკან ჩამოიჭრა.
4. `[შენ]` Season Pass (250 ⭐) და VIP (200 ⭐) ერთხელ საკუთარ თავზე გამოცადე; `[მე]` ვამოწმებ `v_season`-ს.
5. `[მე]` Stars-ის გამოტანა: მინიმუმ 1000 ⭐ და ჰოლდი (`docs/monetization-marketing.md`).

## 2. წყაროს ბმულები
ყველა არხს **თავისი** ბმული აქვს, რომ ვიცოდეთ საიდან მოდის მოთამაშე:

`https://t.me/HoldorTDBot/play?startapp=s_<კოდი>`

| კოდი | სად |
|---|---|
| `s_tg` | შენი Telegram არხი / ჯგუფი |
| `s_yt1`, `s_yt2` … | YouTube ვიდეო / არხი (თითო ვიდეოს თავისი კოდი) |
| `s_x` | X (Twitter) |
| `s_fr` | პირადი, მეგობრები |
| `s_ad1` … | ფასიანი ტესტი (თითო რეკლამას თავისი) |

კოდი: 2–16 სიმბოლო, პატარა ლათინური ასოები, ციფრები, `_`. მოთამაშის მოწვევით მოსული ავტომატურად `ref`-ია.

## 3. რას ვზომავთ (ყველაფერი სერვერის ჩანაწერებიდან; Supabase → SQL Editor)
```sql
select * from v_sources;     -- წყარო: მოთამაშე, პირველი ეტაპი, 5 ეტაპი, გადამხდელი, Stars, Stars ერთ მოთამაშეზე
select * from v_retention;   -- დღე-0 / D1 / D7 / D30 პირველი თამაშის დღის მიხედვით
select * from v_funnel;      -- მოვიდა → პირველი ეტაპი → 5 ეტაპი → 20 ეტაპი → გადაიხადა
select * from v_revenue;     -- Stars დღეების მიხედვით
select * from v_referrals;   -- მოწვევები და რამდენმა მიაღწია მიზანს
select * from v_duels;       -- დუელები
select * from v_season;      -- Season Pass და VIP გაყიდვები
```
პატარა მოთამაშეთა რაოდენობაზე პროცენტები ცრუ სიზუსტეს იძლევა: **ცხრილს ვკითხულობთ, სანამ ერთ წყაროზე ~30 მოთამაშე არ იქნება**.

## 4. გადაწყვეტილების წესი (ორიენტირი, არა დაპირება)
- ჯერ **უფასო არხები** (შენი არხი, მეგობრები, YouTube), მერე მცირე ფასიანი ტესტი.
- არხს ვზრდით მხოლოდ თუ მისი მოთამაშეების ≥ ნახევარი აღწევს მე-5 ეტაპს (`reached_5 / players`) და D1 არ არის ნულთან.
- ფულს ვაბანდებთ იმ არხზე, სადაც `stars_per_player` ყველაზე მაღალია, და არა იმაზე, სადაც ყველაზე მეტი ადამიანი მოდის.
- თუ ჯერ არავინ იხდის, ეს არ ნიშნავს, რომ თამაში ცუდია: `v_funnel`-ში ვნახავთ, სად წყდება (პირველი ეტაპი? მე-5?).
