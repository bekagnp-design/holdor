### v1.0.36 — Supabase backend: cloud save + real leaderboard (2026-09-13)
MR B chose Supabase over Telegram CloudStorage. Design: **no auth provider, no edge functions** — the app (anon key) can call only three `security definer` RPCs; tables are RLS-locked with no policies.
- `backend/holdor_supabase.sql` (also `Desktop/holdor/backend/`): `app_secrets` (bot token), `players` (tg_id, name, house, realm, save jsonb, save_ver), `sessions` (uuid token per login), `scores` (stars/gates/waves/kills, monotonic max). `tg_check(init_data)` validates Telegram Mini App initData in plpgsql (pgcrypto HMAC-SHA256 with key "WebAppData", percent-decoding helper, 7-day auth_date window); `tg_login` → session token + cloud save; `save_progress(token, save, ver, house, realm, stars, gates, waves, kills)` — stores the save only if `ver >= save_ver` (counter, last-writer-wins) and upserts scores; `leaderboard(realm, me)` → realm totals, top 25, my rank. Tested locally in Postgres 16 (valid/tampered initData, anon cannot read tables or call tg_check, older save rejected, scores keep max).
- Client (`SB={url,key}` placeholders `__SUPABASE_URL__` / `__SUPABASE_ANON_KEY__`, `sbReady()` false until baked in): `sbRpc` = plain `fetch` to `/rest/v1/rpc/<fn>` (no supabase-js); `cloudLogin()` in `init()` after `loadSave()` (bounded by a 4.5 s race) — pulls the cloud save when `save_ver > SAVE.ver`, otherwise pushes; `persist()` bumps `SAVE.ver` and debounces `cloudSave` 3 s; flush on `visibilitychange`/`pagehide` with `keepalive`; `bad session` → re-login. `fixSave()` normalises any loaded save (defaults for missing fields). `realmStats()` now reads the real leaderboard (cached in `localStorage` `holdor_lb`); realm screen shows live totals, top-10 defenders with house sigil and my world rank; guests (no Telegram) get read-only standings; Settings shows the cloud status line. Tested end-to-end with a fake Telegram object + a PostgREST-like shim over the local DB: fresh device pulls, second device pulls, newer local pushes, guest read-only.
- Free-tier caveat: Supabase pauses a project after 7 days without requests; restoring is one click in the dashboard.

### v1.0.37 — champion talents, phase B (2026-09-13)
While waiting on MR B's Supabase Project URL/anon key, built the next queued item: talents at champion level 5 (`champions-plan.md` §6.4).
- **98 talents** — 2 per champion — in a new `TALENTS` object keyed by champion id, each `{n(name), k(kind)[, sk(skill id)], v(value)}`. Kept to **10 generic mechanic kinds** so one code path covers every champion instead of 98 bespoke effects: `dmg` +18% base damage, `hp` +20% max HP, `range` +15%, `rate` -15% attack cooldown, `cdr` -20% on all skill/ult cooldowns, `goldkill` +20% gold from the champion's own kills, `block` +1 enemy blocked in melee, `skillmult` +25% (or +18% when the target is an ultimate — Dracarys/Kraken/Poison Cloud etc., kept lower so ults don't spike) to one named skill's `SK[id].v` value, rounded.
- Every talent is picked to fit the champion's real kit and flavor (e.g. Jon: "Longclaw's Bite" +25% Cleave / "Ghost at His Side" +25% Bulwark; Tywin: "A Lion's Command" +25% Rally / "The Lion Pays in Gold" +20% gold on kill; Dany/Euron/Ellaria/Tyene get an ultimate-boosting talent since their kit is otherwise thin on non-ult skills). Full list of 98 is in `champions-plan.md` §0 and in code.
- **Hooks**: `makeHero()` applies dmg/hp/range/rate/spd multipliers and the block bonus at hero creation, and sets `hero.tal`; `skVal(hero,id)` applies the skillmult bonus (rounded) so every existing call site that already used `skVal` — crit, execute, poison, burn, stun, rally, slowaura, goldtouch, multishot, pierce, and the ult itself via `castUlt`'s `skVal(h,id)` — picked up talents for free; the periodic cleave/shield/heal/summon loop in `step()` was changed from reading `SK[id].v[l-1]` directly to `skVal(h,id)` so those four also respect talents; `cdMul(h)` (returns `1-v` for a `cdr` talent) is applied everywhere a skill or the ultimate's cooldown is reset; `kill()` applies `goldkill` the same way `goldtouch` already does.
- **UI**: Hero room, once a champion is level 5, shows a "Talent" section under the skill list with both options as cards (icon + name + one-line effect text generated by `talDesc()`); the chosen one is gold-highlighted with a check mark; tapping the other one swaps instantly and for free, any time (`cprog(id).tal` stores 0/1/2, defaulted defensively for old saves in `cprog()`).

### v1.0.60 — Telegram Stars (backend v9) (2026-09-29)

  2. The function calls `pay_create` (session token checked, price from the server's table, order stored `pending`) and Telegram's `createInvoiceLink`.
  3. The app opens it with `WebApp.openInvoice`.
  4. Telegram sends the function `pre_checkout_query`; `pay_precheck` says yes only for an open order of this payer, this amount, in Stars.
