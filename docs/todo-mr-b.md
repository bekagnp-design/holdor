### 0.2 — ბეტის შემოწმების სია (10 პუნქტი)
1. **დაწყება:** სათაური → სახლი → პირველი გმირი (სახლის პირველი ჩემპიონი) → სახელი → პროლოგი → სახლის ციხეში გაჩენა (Stark → Winterfell და ა.შ.). მენიუს კედელი არსად.
2. **3D რუკა:** მიწა ზღვიდან მთებისკენ იწევს, ზღვაში/მთაში ვერ შედიხარ; გზები და ციხეები (კოშკები + კედელი + სახლის ბანერი) ჩანს; **fps** შენს ტელეფონზე — მოძრაობა გლუვია? (დაწერე ტელეფონის მოდელი).
3. **კამერა:** მარჯვენა მხარეს თითის გასმა კამერას აბრუნებს, ორი თითით zoom (ახლოს/შორს); კამერა გმირის უკანაა და არ „ტოკავს“.
4. **მართვა:** მარცხნივ ჯოისტიკი იქ ჩნდება, სადაც თითი დადე; მარჯვნივ ATTACK (დიდი), DODGE, 3 სქილი რგოლით, წამალი; ყველა ღილაკი ≥ 44 px, თითი არ იკარგება.
5. **პირველი 3 წუთი (ტუტორიალი):** მოძრაობა → კამერა → დარტყმა → სქილი → ლუთის აღება → პირველი ქვესთი; ყოველი ნაბიჯი ერთი წინადადებით.
6. **ბრძოლა:** მობის მოკვლაზე XP/ოქრო HUD-ზე რეალურად იზრდება, ციფრები ეკრანზე; ბოსის/მობის მძიმე დარტყმას **წინასწარ წრე/ზოლი** აქვს (dodge-ით თავს არიდებ); level up → popup სტატებით.
7. **ინვენტარი და ქალაქი:** ნივთის აღება → ჩაცმა → სტატი იცვლება; ციხეში მაღაზია (ოქროთი), სასტუმრო (ჰილი), მჭედელი (upgrade) — ფასები რეალურია და ოქრო აკლდება.
8. **რუკის ეკრანი:** ნისლი იხსნება სადაც იყავი, ნაპოვნი ციხეში სწრაფი გადასვლა მუშაობს; **სხვა მოთამაშე** რუკაზე ჩანს სახელით (მეორე ტელეფონით/ანგარიშით შედი) და **ზონის ჩატში** ერთი შეტყობინება გაგზავნე — მეორეზე ჩანს.
9. **სიკვდილი (permadeath):** განზრახ მოკვდი → ეკრანი: ვინ მოგკლა, შენი ხაზი **Hall of the Fallen**-ში (სახელი, დონე, მკვლელი, დრო) → **შემდეგი გმირის არჩევა** გახსნილი ჩემპიონებიდან → ახალი გმირი დონე 1-ზე სახლის ციხეში; ოქრო/გემები/ნივთები **გაქრა**, გახსნილი კარიბჭეები, ნაპოვნი ციხეები და ჩაბარებული ქვესთები **დარჩა**, ტიტულები დარჩა.
10. **გამოსვლა/შესვლა:** თამაშის დახურვა და ხელახლა გახსნა → იგივე გმირი, პოზიცია, დონე, ინვენტარი (სერვერზე `rpg_saves`); ხმა (ჩართვა/გამორთვა Settings-ში) და ვიბრაცია დარტყმებზე მუშაობს; Telegram-ის Back ღილაკი ეკრანს ხურავს.
